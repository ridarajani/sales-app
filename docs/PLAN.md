# Development plan

Each phase ends with something Rida can try before the next one starts.

| Phase | What it covers |
|---|---|
| 0. Setup | Server, database and an empty Android app in this repo |
| 1. Login and roles | Each person signs in with a PIN and sees only their own companies and screens |
| 2. Basic lists | Companies, customers, products, vehicles and drivers; Excel import for the client's lists |
| 3. Orders | Booking with typed prices, one LPO per company, stock held for the order |
| 4. Loading plans and warehouse | Plan the vehicle, send it to the warehouse, load it, print the gate pass |
| 5. Invoices and delivery | Invoices from the loading plan; driver delivers with signature and photo, records shortages |
| 6. Collections and cashier | Payments, discount at collection, WHT, cash handover |
| 7. Returns and notes | Sales returns, credit and debit notes, customer ledger |
| 8. Trips | Minibus and upcountry sales, working offline |
| 9. Reports and dashboard | Management and accounts website, client testing, go-live |

The agreed behaviour is the clickable prototype (`index.html`) plus the client's brief of 16 October 2026.
